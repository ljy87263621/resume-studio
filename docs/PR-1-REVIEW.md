## 合并方式与边界

通过可由维护者修改的原贡献分支追加集成提交，正常推送，不强推、不改写贡献者提交。GitHub 检查通过后以 Merge commit 合入 main，并用已审核的贡献分支 HEAD 限制合并，避免混入检查后出现的改动。合并后本机 main 仅作快进同步。

真实 BOSS／牛客登录、线上 WebDAV 服务和干净 Windows 分发仍未验收。本机 HTTP fixture 通过不代表线上平台完整流程通过。本次为代码审核与主分支集成，不新增正式版本标签或替换用户已安装程序。
