# v0.7.0 使用与实现范围

## 模板照片预览

模板中心的卡片并排显示有照片占位和无照片两种版式。两种预览使用实际简历渲染器生成；无照片时不保留空白照片框。占位轮廓仅用于模板预览，新建简历没有照片。上传和移除真实照片仍在“基本信息”，打印与导出沿用相同排版。现有 14 套模板均支持照片。

## 求职日程

侧栏“求职日程”提供月历和所选日期／近期 30 天／全部未完成列表。日期色条表示未完成事项，点击日期查看当天安排；可以搜索事项、公司和备注。

独立日程支持笔试、面试、投递截止、跟进和自定义事项，选择日期、时间或全天，关联投递可选，备注可记地点和会议链接。可编辑、标记完成、恢复待办或确认删除。保存于数据目录 `schedule/`，沿用原子替换与压缩旧版备份。

投递记录的 `dueAt` 作为动态视图汇总，不复制为另一份日程。日期、类型、完成状态修改回原投递记录；已录用／已结束记录不再提醒。独立日程即使关联投递，也保留自己的完成状态，删除投递不会删除独立日程。

提醒可关闭，或设提前一天、一小时、15 分钟、到点。关闭软件时不触发系统通知，重新打开检查未处理事项。同一会话避免重复显示同一提醒阶段。全天事项当天仍为待办，次日才显示过期。

## 字体

界面统一 MiSans。新简历以及没有字体字段的旧简历默认 MiSans；通过“排版设置 → 简历字体”选择 MiSans、微软雅黑、宋体、Arial、Times New Roman。其他字体依赖本机安装，缺失字形或字体时回退到 MiSans。

MiSans 原文件取自小米官方字体包，字体、许可和来源随应用分发。预览通过本机 WebView2 虚拟主机加载字体，不向网络发送简历，PDF 导出等待字体加载完成并嵌入所用字形。原模板的单双栏、分节与配色保持，文字使用所选字体。

## 验证入口

- `scripts/test-offline.ps1`：后端日程 HTTP、验证与持久化，以及模板 UTF-8 校验。
- `scripts/test-schedule.ps1`：日期、全天、提前提醒、完成状态和投递投影逻辑。
- `--feature-test`：隔离数据下验证原生日程对话框、双版模板预览、字体选择、MiSans PDF 及既有功能。
- `--template-assets`：使用实际 WebView2 与渲染器生成双版缩略图，校验照片占位状态和 MiSans 实际加载。
