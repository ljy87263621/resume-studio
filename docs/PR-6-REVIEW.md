# PR #6 集成与修复

基于贡献提交 `1baae80ebb691a69839f0d30d530b8f36602c9ab`，保留排版、可编辑 Word 导出及自适应工作台；官方更新仓库、公钥与发布配置保持不变。

- Word 对同一 data URL 复用媒体载荷，每个绘图仍分配独立标识，保留各自尺寸、标题与说明。原先约 0.8 MB 的文档重复引用图片 160 次会在 64 MiB 堆下内存不足；新增回归在同样限制下验证 161 次跨模块引用以及不同图片不被错误合并。
- Word 表格按展开后的总单元格数限制为 10,000，避免稀疏 Markdown 的行列补齐产生无界内存增长；超限返回明确错误。
- 文件窗口取消不再从工作线程调用 COM Close。取消定时器只向所属窗口、同进程同线程的原生弹窗投递 Cancel，并在窗口结束时清理，避免跨线程阻塞及资源泄漏。

验证：Release 分发构建；离线与 Word 内存边界、功能／同步、工作台／排版、维护回归；72 项原生工作台／PDF 检查；最终 Release 文件窗口完整验收连续两轮通过。构建仍有现有的 .NET 裁剪分析提示，不将构建成功描述为无警告。

使用隔离测试资料，没有使用真实 WebDAV 凭据或修改用户已安装程序。本次为代码集成，不主动发布 Stable。
