# v0.4.2：应用体积、整体玻璃与职位收藏

## 应用分发体积

改用 `Microsoft.WindowsAppSDK.WinUI` 及其必需依赖，不再引用整个 SDK 元包。未使用的 ONNX Runtime、DirectML、AI / ML 与 Widgets 组件不进入分发包；禁用客户端调试符号。Java、.NET 与 WinUI 继续自包含，14 套模板、第三方源码与许可证保持完整。

同机 Windows x64 构建，应用目录文件总大小从 v0.4.1 的约 **242 MiB** 降至约 **192 MiB**，减少约 **21%**。这里统计分发文件字节总数，不包含系统共享 WebView2 Runtime 或个人数据。

构建在空的暂存目录组装程序，生成逐文件 SHA-256 分发清单。打包只接受清单内已验证的文件。更新时先完整复制、校验新版，再删除旧清单中已不需要且哈希仍匹配的程序文件；用户修改的额外文件不删除。旧版无清单时可用 `-PreviousSourceDirectory` 指定原始分发目录来安全迁移。

## 整体玻璃界面

Haru 优先使用与 haruphoto 相同的 DWM 整窗亚克力路径，不支持时回退到 WinUI 的 Desktop Acrylic。侧栏、顶栏、内容卡片、模块导航与工具栏叠加半透明色层和高光描边。清除 NavigationView 默认实心内容背景，标题栏与预览纸张周围也透出材质。使用共享窗口模糊，避免每张卡片重复做模糊；材质遵循 Windows 的透明效果与辅助功能设置。

经典界面保持默认；设置中的浅色、深色和跟随系统继续适用。简历纸张与 PDF 仍保持白底。隐藏窗口时预览完成标记不依赖 `requestAnimationFrame`，防止导出等待绘制回调超时。

## 职位链接与解析

- 收藏与职位卡片显示可打开的原始链接，并提供复制按钮。规范化地址只用于去重，不再丢掉打开页面所需的访问参数。
- 粘贴链接后尝试从公开 JSON-LD / 网页元数据提取职位、公司、地点、薪资与描述。普通招聘首页、验证页不当成职位详情。
- 访问验证 / 登录后的页面可使用“浏览并读取”：用户正常访问页面后主动读取可见职位信息，再核对保存。不会自动解决验证、读取外部浏览器 Cookie 或同步平台账号收藏。
- 多行分享文本先启用多行输入再赋值，避免后续链接与描述被截断。已有收藏可点击“自动补全”，或重新浏览读取。
- 列表采用标准原生 DataTemplate，在容器回收后正确刷新职位卡片；平台筛选未就绪时按“全部平台”显示，避免初始化空结果。

## 验证范围

13 项离线职位解析检查覆盖：原始访问参数、规范去重、Markdown 链接、JSON-LD 职位 / 公司 / 地点 / 薪资、可读描述、验证页和招聘首页排除、元数据与可见字段映射、本机地址拒绝。

桌面验证覆盖原有 19 项完整流程与 9 项界面 / 工作台检查：14 套模板 PDF、多页导出、自动保存、真实职位查询、收藏和投递记录、1000 条虚拟列表、双界面 / 主题切换、隐藏窗口导出、可见页面字段读取、原始链接持久化与原生收藏卡片显示。真实 BOSS 链接的匿名访问返回验证页；正常完成网站验证后的实际登录态页面需用户在自己的会话中完成验证与读取。
