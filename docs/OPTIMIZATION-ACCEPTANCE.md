# 双端优化实施与验收

本轮先完成双端本机验收，再发布 Nightly 测试版；Android 与桌面更新通道保持独立。

按顺序实施：

1. 同步安全：双方变化暂停自动同步；冲突预览与按记录选择；校验和备份继续保留。
2. 安卓网页收藏：安全区域、后退/刷新/进度、明确收藏结果、保留页面与滚动位置。
3. 更新体验：阶段、百分比、速度、取消重试、错误详情；失败检查不占用成功检查间隔。
4. 日程通知：安卓系统通知及重启恢复；桌面系统通知；日历文件导出。
5. 背诵：断点续读、今日复习、随机抽题、间隔复习，进度可同步。
6. 备份恢复：时间、来源、数量、预览、导出与单条恢复。
7. 简历导出：分页/空白/溢出预检、可编辑 DOCX。
8. 求职管理：标签、批量状态、跨模块搜索、截止及未跟进提示。

## 验收边界

Android 系统通知在模拟器验收；提醒使用系统非精确闹钟，强行停止、关闭通知权限或厂商省电策略可能影响送达时间。WebDAV 互操作使用本机测试服务覆盖强/弱/无 ETag 和拒绝通配写入；本轮没有重新连接用户配置的蓝奏云/Alist 服务。ICS 需导入用户自己的日历。Windows 安装后已打开本机资料目录验证，升级前旧程序按自身保存和关闭流程退出。
