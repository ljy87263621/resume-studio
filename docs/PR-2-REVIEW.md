# PR #2 与 WebDAV 兼容修复

PR #2 已通过原提交的 Windows CI 和独立工作区的同步测试，并以 Merge commit 合入 main。官方更新仓库、公钥与发布配置未改变。本机已有的 Android 开发改动已保留。

该 PR 支持自动创建桌面端同步目录、缺失／弱 ETag 的内容版本令牌以及上传回读。真实服务验证发现：部分服务对存在的文件仍拒绝 If-Match: *，因此追加一次受限的兼容重试。只有内容指纹模式会触发重试；收到 412 后重新读取，内容完全未变才继续，出现强 ETag 则使用该条件，否则用内容校验上传。首次创建与强 ETag 失败不会降级，变化或删除仍拒绝。无强 ETag 无法消除最后检查与 PUT 之间的并发窗口，请同一时间只在一台设备同步。

配套 Android 本机实现采用相同内容指纹和重试规则。已通过 41 项 Windows／Android 互操作检查、41 项桌面原生导航检查以及 41 项正式 APK 模拟器界面检查；后者包含无 ETag 且拒绝通配条件的实际 HTTP 上传和覆盖回读。真实 WebDAV 在独立临时目录完成桌面上传、Android Java 同步器下载／覆盖、桌面回读校验；未改变正式同步文件。

真实服务测试只在本机内存读取加密配置，通过本机进程管道传递凭据；输出脱敏，不保存账号、目录 URL 或密码。源码扫描未发现用户配置值，测试与构建输出不提交。真实手机尚未连接，需安装配套修复 APK 才能使用 Android 修复。
