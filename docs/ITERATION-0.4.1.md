# v0.4.1 本机存储优化

本版本减少简历副本和照片占用，并提供可见的本机存储用量与安全缓存清理入口。

- 每份文档仅保留上一完整版本，使用 gzip 写入 `.json.bak.gz`，并在原子替换前完成备份写入。删除文档时同时删除压缩备份；旧 `.json.bak` 在下一次成功创建压缩备份后迁移清理。
- 后端 `backend.log` 达到 256 KiB 时轮转为 `backend.log.1`，仅保留当前日志和一个上一份日志。
- 证件照导入后按原比例缩放到最长边不超过 640 像素，再以内嵌 JPEG 保存；原始文件不修改。
- 设置页显示简历与求职记录、备份、预览缓存、日志和总占用。清理按钮通过 WebView2 只清理磁盘缓存，不清除本机文档、备份或站点数据。

旧版本已有的未编辑文档与备份不会被自动扫描或删除。备份迁移只在保存对应文档时进行，且在新压缩副本写成功后才移除旧副本。
