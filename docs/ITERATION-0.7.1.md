# v0.7.1 交互优化

## 全局反馈

页面内容使用 WinUI 入场过渡；卡片悬停高亮并轻微缩放，按钮悬停放大、按下缩小并缓动恢复。设置中的“交互动效”可关闭自定义动画，Windows 关闭动画时自动减少动效。展开和键盘操作仍然可用。

按钮操作超过约 180 ms 显示进度，执行期间不可重复提交；失败也会恢复按钮并显示错误。新增底部反馈条供成功提示和日程撤销使用，与到期提醒和错误栏分开；默认八秒后消失，鼠标停留时暂停计时。

## 简历编辑

内容目录显示填写进度，统计姓名、求职意向、至少一种联系方式和当前可见模块是否已填写，不评价内容质量。联系方式和身份信息可展开／折叠，折叠不会丢失输入。模块编辑显示实时字符和行数；模块显示与顺序选项也可收起。

Ctrl+S 保存，Ctrl+Z／Ctrl+Y 撤销／重做，内容框 Ctrl+B 对选中内容加粗。悬停工具按钮可查看操作说明。撤销和重做位于主工具栏，空间不足时由原生工具栏收入溢出菜单。

“在预览中定位模块”按模块的原始索引滚动，重复标题不会混淆；隐藏模块会提示打开显示。高亮只在预览中短暂显示，打印样式强制移除背景色。

## 日程

新增今日、近七天和已到期待办统计，其中近七天为今天至第六天，排除已过时点。列表支持类型与搜索组合筛选，空结果可清空筛选。月历下四个快速添加按钮预选日期和事项类型，保存前仍可修改。

卡片标题、时间、类型和完成状态始终显示，备注和提醒说明可展开；本次会话按事项 ID 保留展开状态。完成后显示可撤销反馈，撤销前重新读取当前数据，只更新完成字段并保留后续编辑；已删除、当前完成状态与操作结果不符或投递已结束时不会覆盖记录。

## 验证

`--feature-test` 使用隔离数据执行实际原生控件、按钮进度和防重入、异常恢复、Composition 缩放、折叠输入保留、预览定位、日程完成／撤销及动效设置持久化验证，并继续覆盖模板、字体、PDF 与投递流程。

`--iteration-test` 验证 Haru 拖动区域、主题与紧凑窗口、预览实例复用、自动保存和隐藏窗口 PDF 导出。离线、更新事务和日期边界验证继续使用现有脚本。
